# 富文本编辑器操作指南

出题、比赛说明、评论等地方用的是同一套编辑器。上面可以在「富文本」和 Markdown 之间随时切换，工具栏两边都能用。你在编辑框里看到的格式，就是学生在题面、作业和比赛说明里看到的格式。

点工具栏右侧的问号，也可以在编辑器里打开这份说明。

## 两种编辑方式

- **富文本**：像 Word 一样点选格式，适合大多数人。
- **Markdown**：直接写标记，适合习惯源码的人。切过去再切回来，内容会保留。

## 常用格式

先选中文字，再点工具栏：

| 按钮 | 作用 |
| --- | --- |
| 正文 / 标题 | 段落或三级标题 |
| **B** / *I* / 荧光笔 | 加粗、斜体、高亮 |
| `<>` / 文件代码 | 行内代码、代码块 |
| 引号 | 引用（淡蓝色背景） |
| 列表 | 无序或有序列表 |
| 对齐 | 左、中、右 |

换行：按 Enter 就是换行。需要新段落时，空一行再写。

在代码块里按 **Ctrl+Enter** 可以跳出代码块。

## 公式

1. 点工具栏的公式按钮（或 **Ctrl+Alt+D**）。
2. 在符号板上点需要的符号。出现虚线方块时，直接点进去填字母或数字。
3. 向量、期望值（帽）、上划线也是同样：先点符号，再在方块里写内容。
4. 已经写好的公式，点一下就能再改。
5. 只有需要手写 LaTeX 时，再勾选「直接编辑 LaTeX」。

Markdown 里用 `$$a^2+b^2=c^2$$` 写公式。行内也可以用 `\(...\)`。

## 表格、图片、链接

- **表格**：点表格按钮，拖选行列数。点单元格旁边的菜单可以增删行、列，或删掉整张表。
- **图片 / 附件**：点回形针上传，或直接把图片粘贴进编辑框。每天有上传次数上限。
- **链接**：点链接按钮（或 **Ctrl+L**），填文字和网址。
- **提及**：点 @（或 **Ctrl+M**），搜索用户名。

## 填空题

出填空题时，工具栏会出现空格按钮。每插一个空，题面会显示成编号芯片，例如 `(1)`、`(2)`。

在 Markdown 里写 `{{blank}}`，效果相同。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 加粗 | Ctrl+B |
| 斜体 | Ctrl+I |
| 引用 | Ctrl+Q |
| 无序列表 | Ctrl+U |
| 有序列表 | Ctrl+Shift+O |
| 链接 | Ctrl+L |
| 提及 | Ctrl+M |
| 公式 | Ctrl+Alt+D |
| 关闭弹窗 | Esc |

Mac 上用 Command 代替 Ctrl。

## Markdown 速查

| 效果 | 写法 |
| --- | --- |
| 加粗 | `**文字**` |
| 斜体 | `*文字*` |
| 高亮 | `<mark>文字</mark>` |
| 行内代码 | `` `code` `` |
| 公式 | `$$a^2+b^2=c^2$$` |
| 填空 | `{{blank}}` |
| 链接 | `[文字](https://…)` |
| 图片 | `![说明](网址)` |
| 提及 | `[user:用户名]` |
| 表格 | `\| 列1 \| 列2 \|` |

更完整的 Markdown 语法见 [CommonMark](https://commonmark.org/help/)。
